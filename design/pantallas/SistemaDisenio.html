Móvil para operar, web para gestionar
La misma pantalla no se resuelve igual en los dos sitios. El vendedor, el mesero y el recepcionista trabajan de pie y con una mano: listas, botones grandes, escáner a un toque. El dueño configura atributos, revisa cartera y factura sentado: tablas densas, paneles laterales, varias cosas a la vez. Es el mismo código Flutter y el mismo backend — lo que cambia es la composición.
